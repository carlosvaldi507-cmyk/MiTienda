# Imágenes de productos

Organiza cada imagen dentro de la categoría correspondiente.

## Convención de nombres

Usa minúsculas, guiones y un número de vista:

```text
nombre-del-producto-01.webp
nombre-del-producto-02.webp
```

Evita espacios, tildes y nombres genéricos como `imagen1.png`.

## Recomendaciones

- Formato preferido: WebP o AVIF.
- Proporción recomendada: 1:1.
- Peso objetivo para tarjetas: menos de 150 KB.
- Usa `01` para la imagen principal.
- Guarda las imágenes genéricas en `assets/placeholders`.

## Ruta en productos.js

```js
imagen: "assets/productos/termos/termo-hello-kitty-500ml-01.webp"
```
